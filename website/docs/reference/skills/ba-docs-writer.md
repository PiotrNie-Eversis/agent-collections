# BA Docs (Word) writer

**Folder:** `.ai/skills/eversis-ba-docs-writer/`  
**Used by:** Business Analyst

Applies an **approved** `docs-update-plan.md` to a Word `.docx` file via the `eversis-collections` MCP (BA Docs / Business Manager Docs channel).

**Do not use** for repository Markdown (README, CHANGELOG, `website/docs`, `/docs`) — that is the Repo Docs channel ([`eversis-repo-docs-writer`](../prompts/public/repo-docs-writer) when shipped).
