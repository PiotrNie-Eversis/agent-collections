# BA Docs (Word) planner

**Folder:** `.ai/skills/eversis-ba-docs-planner/`  
**Used by:** Business Analyst

Plans Word `.docx` chapter updates from a Jira release plus Confluence rules, producing `docs-update-plan.md` — not repository Markdown. Apply it before handing off to the Writer; the plan must be BA-approved before the Writer acts.

Load this skill before any planning run that involves `.docx` documentation (e.g. release notes using a `summary.md` + `chapter_id` scheme).
