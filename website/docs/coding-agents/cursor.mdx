# Agent Collections in Cursor

Cursor applies two rules to every request and keeps the role rules attach-only. The Engineering Manager role delegates research, planning and code review to the role subagents (Context Engineer, Architect, Code Reviewer), so review runs in a separate context by default; these subagents come from `.claude/agents/`, so they are available only when Claude Code is selected too. Implementation is delegated with the `eversis-implement-common-task` prompt; it has no dedicated subagent file.

## The delivery cycle

Each stage shows what the process does and which Cursor tools do the work. Quick Flow can skip Research and Plan.

### Tools at each stage

| Stage | Kind | Tool | Note |
| --- | --- | --- | --- |
| Ideate | Process | Agent Collections | Turns workshop materials into Jira-ready stories. |
| Ideate | Command | `/eversis-analyze-materials` | Optional. Starts from workshop materials. |
| Start | Process | Agent Collections | Prints the Implement readiness block and picks Quick or Full. |
| Start | Command | `/eversis-implement <ticket>` | Or attach `@eversis-implement`. |
| Start | Rule | `.cursor/rules/*.mdc` | Two rules always on, accessibility for UI files, four attach-only. |
| Research | Process | Agent Collections | Gathers context and writes `*.research.md`. You approve research before Plan starts. |
| Research | Sub-agent | `eversis-context-engineer` | Context Engineer. Runs the `eversis-research` prompt. Comes from `.claude/agents/`, which Cursor also reads; that folder is installed only when Claude Code is selected too. |
| Research | Skill | `.cursor/skills/eversis-orchestrating-implementation` | — |
| Research | MCP | `eversis-collections`, `atlassian` | Skills, domain context and the ticket. |
| Plan | Process | Agent Collections | Writes `*.plan.md` with phases and acceptance checks. |
| Plan | Sub-agent | `eversis-architect` | Architect. Runs the `eversis-plan` prompt. Comes from `.claude/agents/`, which Cursor also reads; that folder is installed only when Claude Code is selected too. |
| Plan | Skill | `.cursor/skills/eversis-creating-implementation-plans` | — |
| Plan review | Process | Agent Collections | Checks the plan before you see it. Only a BLOCKER sends it back to Plan, at most three rounds. You approve the plan before Implement starts. |
| Plan review | Role | Plan Reviewer | Runs the `eversis-review-plan` prompt and writes `*.plan-review.md`. There is no generated sub-agent file for this role: the Engineering Manager delegates it. |
| Implement | Process | Agent Collections | Changes the code, then runs lint, typecheck and tests. |
| Implement | Role | Software Engineer | Runs the `eversis-implement-common-task` prompt. There is no generated sub-agent file for this role: the Engineering Manager delegates it. |
| Implement | Tools | file edits and terminal | — |
| Review | Process | Agent Collections | Reports PASS, BLOCKER or SUGGESTION against the plan. BLOCKER goes back to Implement; PASS goes on to Fine. |
| Review | Sub-agent | `eversis-code-reviewer` | Code Reviewer. Runs `eversis-review` in a separate context, in the same Implement run. It can read files and run checks, but has no edit tools and is read-only. Comes from `.claude/agents/`, which Cursor also reads; that folder is installed only when Claude Code is selected too. |
| Fine | Process | Agent Collections | Writes the QA comment draft in the same turn. You approve publishing. |
| Fine | Skill | `.cursor/skills/eversis-fine-handoff` | — |
| Fine | MCP | `atlassian` | Posts the comment only after approval. |

## How the rules load

| Rule | Loads |
| --- | --- |
| `eversis-agent-core`, `eversis-testing-and-terminal` | Always |
| `eversis-accessibility` | For matching UI files |
| `eversis-engineering-manager`, `eversis-code-reviewer`, `eversis-fine-handoff`, `eversis-spec-driven-development` | Attach-only |

## What gets installed

| Path | What it holds |
| --- | --- |
| `.cursor/rules/eversis-*.mdc` | Rules, plus your `eversis-project-stack` policy |
| `.cursor/commands/eversis-*.md` | Thin slash commands for the prompts in `.ai/prompts/` |
| `.cursor/skills/eversis-*/` | Skill packages, linked or copied by the installer |
| `.cursor/mcp.json` | MCP servers, including `eversis-collections` |

Generated files are overwritten on the next sync, so do not edit them by hand. `eversis-project-stack` is yours to edit.

For setup, see [Installation](../getting-started/installation.mdx) and [MCP Setup](../getting-started/mcp-setup.mdx).
