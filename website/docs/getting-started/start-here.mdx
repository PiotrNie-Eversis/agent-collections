# Start here

**Agent Collections** is a **vendor-neutral** multi-agent product engineering framework. Canonical content lives under **`.ai/`**; adapters package it for Cursor, Claude Code, the Pi coding agent (opt-in), and (placeholder) OpenCode.

> **Ideate → Research → Plan → Implement → Review → Fine**

Each phase produces documented artifacts; the next step waits on **your approval** where the prompts require it.

:::tip New to this framework?
Pick your role below and follow that path in order. Each step links to the detailed playbook — this page is the map, not the encyclopedia. Prefer a **sample consumer project** (empty folder or small repo) for your first install.
:::

## Choose your path

<Tabs groupId="start-here-role">
<TabItem value="qa-ba-po" label="QA / BA / PO" default>

**Recommended:** start with **Cursor** (a desktop app). Open [Prerequisites](/docs/getting-started/prerequisites) for the full tool checklist, then [Installation](/docs/getting-started/installation).

1. **[Prerequisites](/docs/getting-started/prerequisites)** — Install an AI editor (**Cursor** and/or **Claude Code**), **Docker Desktop**, and **Git**. Details and accounts live on that page.
2. **[Installation](/docs/getting-started/installation)** — Clone the framework and run the installer on your sample project. Follow the on-page steps; you do not need to memorize shell flags here.
3. Confirm the install left the expected project folders (see [You’re done when…](#youre-done-when) below). Domain knowledge starts at [Domain Context (SSOT)](/docs/domain-context).
4. Open your project in **Cursor** and attach **`@eversis-implement`** (or load prompt id `eversis-implement`) with a short task.

</TabItem>
<TabItem value="developer-qa-tech" label="Developer / QA tech">

Use **Cursor** and/or **Claude Code** — or the **Pi coding agent** (a terminal agent; opt-in, add `pi` to `--agents`). Read [Prerequisites](/docs/getting-started/prerequisites) first (including Node.js notes if you use Claude Code or Pi), then [Installation](/docs/getting-started/installation).

1. **[Prerequisites](/docs/getting-started/prerequisites)** — Install an AI editor (**Cursor** and/or **Claude Code**), **Docker Desktop**, and **Git**. Details and accounts live on that page.
2. **[Installation](/docs/getting-started/installation)** — Clone the framework, set `AGENT_COLLECTIONS_HOME` as shown there, and run the installer on a sample consumer project.

4. Optional: [MCP setup](/docs/getting-started/mcp-setup) if you enable the skills server beyond the installer defaults.
5. Open the consumer project in your agent tool and attach **`@eversis-implement`** with a short task. In Pi, grant project trust first, then run **`/eversis-implement`** — see [Add the Pi coding agent](/docs/getting-started/installation#pi-coding-agent).

## You’re done when…

Your first install succeeded when:

- The installer finished **without an error**.
- The consumer project has **`.agent-collections/`** (including `install-selection.json`) and **`docs/context/<project>/INDEX.md`**.
- In your AI editor, a first **`@eversis-implement`** (or `eversis-implement`; `/eversis-implement` in Pi) prompt gets a normal response — for example an Implement readiness block in chat.
