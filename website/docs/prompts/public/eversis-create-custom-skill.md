# eversis-create-custom-skill

**Role:** [Cursor customization orchestrator](../../agents/cursor-customization-orchestrator)  
**File:** `.ai/prompts/public/eversis-create-custom-skill.md`

Creates a new **skill package** (`SKILL.md`): a directory under **`.ai/skills/<name>/`** with optional `references/`, `assets/`, `examples/`. In this framework, the agent **reads** skills through the current host's native mechanism, or through the **`eversis-collections` MCP** server (`eversis_skills_*` tools) after you build [`mcp/eversis-collections-mcp/`](https://github.com/PiotrNie-Eversis/agent-collections/tree/main/mcp/eversis-collections-mcp) — which channel applies depends on the adapter in use.

## Usage

```text
eversis-create-custom-skill
<skill requirements or description>
```

## What it does

1. **Research** — Study existing **`.ai/skills/eversis-*/SKILL.md`** for frontmatter, gerund folder names, and progressive disclosure.
2. **Clarify** — Domain, when the skill applies, and what templates/references to add.
3. **Create** — New folder with `SKILL.md` per **`eversis-creating-skills`**.
4. **Review** — Naming, description field quality, and folder layout.

## Output

A new **`.ai/skills/<gerund-name>/`** tree.

- `eversis-creating-skills`

## Executable prompt (attach in Cursor)

1. Load `.ai/skills/eversis-creating-skills/SKILL.md` and follow it end-to-end.
2. New skill folders use **gerund** names (e.g. `reviewing-invoices`) matching the skill’s `name` in frontmatter.
3. Ensure the **description** field is specific so the agent matches the skill when appropriate.
4. Do not reference VS Code Copilot — skills are consumed through the current host's native mechanism, or via the **`eversis-collections` MCP** and `eversis_skills_*` tools, depending on the adapter.
