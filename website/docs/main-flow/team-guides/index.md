# Team Guides

**Agent Collections** works across a whole product team, not just one role. Pick your role below for a focused, task-oriented guide: what the framework does for you specifically, your first concrete step, and how your work connects to everyone else in the **Ideate → Implement → Review → Fine** lifecycle (the framework's phase sequence — see [Workflow Overview](../workflow/overview)).

| Role | What you get | Guide |
| --- | --- | --- |
| **Web Developer** | UI implementation with a built-in Figma verification loop | [Web Developer](./web-developer) |
| **Backend Developer** | Structured implementation with reused project conventions | [Backend Developer](./backend-developer) |
| **DevOps** | Infrastructure, CI/CD, and cloud-cost automation with human review gates | [DevOps](./devops) |
| **Business Analyst** | Workshop materials turned into Jira-ready epics and stories | [Business Analyst](./business-analyst) |
| **Project Manager** | Visibility into every approval gate and the Fine handoff, without a dedicated command (see the guide for why) | [Project Manager](./project-manager) |
| **QA Engineer** | One entry point for test planning, regression, AC verification, and quality health | [QA Engineer](./qa-engineer) |
