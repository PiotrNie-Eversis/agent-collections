# Architecture design (seed)

> **Seed** from skill `eversis-architecture-designing` (process outline). Full design playbooks arrive in **TASK-520**.

## Process

1. **Understand the goal** — Read the task, research artifact, and business intent before proposing structure.
2. **Analyse the current codebase** — Prefer extending existing patterns over introducing parallel architectures.
3. **Clarify ambiguity** — Ask before locking irreversible boundaries or technology choices.
4. **Design a solution** — Cover boundaries, data flow, failure modes, and fit with the project stack.
5. **Plan implementation** — Hand off to an implementation plan (`*.plan.md`) with verifiable tasks.

Keep designs proportionate to the problem (YAGNI). Record trade-offs that affect multiple domains (frontend, backend, devops, shared types).
