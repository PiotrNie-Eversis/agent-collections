# Skills (core)

Tool-neutral skill packages live here as flat `eversis-<topic>/` directories (same identity model as the legacy Cursor Collections catalog).

**Consumption:** Prefer MCP `eversis_skills_list` / `eversis_skills_get` / `eversis_skills_validate` (the server resolves from this tree). Without MCP, read `SKILL.md` (and `references/`, `scripts/`) under `.ai/skills/` directly. Do not require Cursor Agent Skills UI registration for core workflows.

Adapters may surface or symlink these packages for IDE UX; this tree remains SSOT.
