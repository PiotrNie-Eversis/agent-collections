## Task Details

| Title            | Installer --upgrade removes or overwrites already-installed MCP servers and CLAUDE.md |
| Description      | `--upgrade --sync` (and `--sync` with partial flags) prunes catalog MCP servers, re-templates their config, and removes Claude surfaces whenever `install-selection.json` lists less than the project has; the uncommitted `upgrade.sh` attempt additionally lets the generator overwrite a hand-written `CLAUDE.md`. |
| Priority         | High |

## Wildly Important Goal

**Goal**: A re-run of the installer on an existing project (`--upgrade` / `--sync` without explicit `--mcp-servers` / `--agents`) never deletes or overwrites MCP server entries, Claude/Cursor surfaces, or a hand-written `CLAUDE.md` that are already installed.

**Success Measure**: New unit tests reproducing S1–S4 and the Gap 3–6 cases pass, and the existing suites (`selection-ssot`, `mcp-merge`, `claude-settings-merge`, `scaffolding`, `gitignore`, `ssot`, `vendor-sync-skew`, `framework-home`, `run-eversis-collections-mcp`) still pass.

**Do NOT touch / do NOT add**: no new npm dependencies; no change to `mcp-server-list.json`, `templates/mcp.json`, or the `install-selection.json` schema fields; no Cursor `.mdc` / `.cursor/commands` deselect-pruning (pre-existing gap); no change to first-install (no record) behaviour except the `CLAUDE.md` backup; no edits to generated files by hand (`CLAUDE.md`, `.claude/commands/*`).

## Proposed Solution

Apply the existing install-record contract ("omitted flag → recorded value, explicit flag → override", introduced for `ssot.*` in `upgrade-sync-ssot-repo-wipe`) to agents, MCP servers and profile, and stop the destructive steps from acting on drift between the record and disk.

```text
                       record exists?
                            │ yes (--upgrade, or --sync)
                            ▼
  load_selection_or_fail ── per field ──► --agents passed?      → ARG_AGENTS (spaces stripped)
                                          else                  → record ∪ marker-detected agents
                                          --mcp-servers passed? → ARG_MCP_SERVERS, PRESERVE=false
                                          else                  → record, PRESERVE=true
                                          --profile passed?     → ARG_PROFILE
                                          else                  → record
                            │
           ┌────────────────┼──────────────────────────┐
           ▼                ▼                          ▼
   _prune_deselected   mcp-merge.mjs (per host)   claude-settings-merge.mjs
   (unchanged; acts    PRESERVE=true:             PRESERVE=true:
   only on agents      • keep every existing      enabledMcpjsonServers =
   really deselected)    entry of THIS file         selection ∪ catalog ids
                       • regenerate                 present in .mcp.json
                         eversis-collections
                       • add missing selected
                         ids from template
                       • never delete
                            │
                            ▼
   write_install_selection — record = selection only (preserved-only ids NOT written back)
```

Agent detection (marker-gated, Gap 2):

| Agent | Evidence that the framework installed it |
|---|---|
| `claude` | root `CLAUDE.md` contains `GENERATED by adapters/claude/generate.mjs`, **or** any `.claude/commands/eversis-*.md` contains `GENERATED by adapters/claude/generate-commands.mjs` |
| `cursor` | any `.cursor/commands/eversis-*.md` or `.cursor/rules/eversis-*.mdc` contains `GENERATED by adapters/cursor/generate.mjs` (`GENERATED_MARKER`, `adapters/cursor/generate.mjs:18`; written at L287 rules, L474 commands) |

Generator safety net (Gap 6): `writeClaudeMd` copies an existing root `CLAUDE.md` that is a regular file **without** the generator marker to `CLAUDE.md.pre-agent-collections.bak` (overwrite an older `.bak` only if it is byte-identical; otherwise suffix with a timestamp), prints a warning that points to `.claude/CLAUDE.md`, then writes as today. Symlinks and marked files keep today's unlink-and-write path.

Explicit `--mcp-servers` keeps today's semantics (replace record, re-template selected, prune deselected catalog ids) — this is the documented refresh / deselect path.

### Architecture & Patterns

- `scripts/setup-agent-collections.sh` parses flags into exported `ARG_*`, sources `scripts/lib/setup-agent-collections/*.sh`, runs steps in fixed order (see research call path).
- Bash modules set/export globals (`SELECTED_AGENTS`, `MCP_SELECTED_IDS`, `MCP_CONFIGURED_SERVERS`, `DOMAIN_PROFILE`); resolvers early-return when the global is already set.
- Non-trivial JSON logic lives in `.mjs` driven by env vars (`MCP_*`, `CS_*`); bash only passes values.
- Ownership markers: `GENERATED by adapters/claude/generate.mjs`, `GENERATED by adapters/claude/generate-commands.mjs`, `Agent Collections ignore triad`.

### Tech Stack

- Bash (`set -euo pipefail`, macOS bash 3.2 compatible — no associative arrays, no `${var,,}`), Node ≥ 18 ESM `.mjs`, no npm deps in installer helpers.
