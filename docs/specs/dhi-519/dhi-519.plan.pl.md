## Najważniejszy cel

**Cel**: Każdy z pięciu folderów domenowych ma co najmniej jeden vendor-neutral plik reguły (z legacy `.mdc` lub seed ze skilli), bez dublowania orchestration i bez portu pełnych skilli.

**Miara sukcesu**: Pięć domen z ≥1 `.md` reguły; brak wymaganego IDE/CLI/UI vendora; `code-reviewer` w architecture; seed udokumentowany; Code Reviewer bez blockerów względem AC.

**Nie ruszać:** BA docs (Q3); project-stack w `.ai/` (Q4); kopia testing-and-terminal (Q5); pełne body skilli (DHI-520); zmiany w `cursor-collections` / adapterach.
