## Wildly Important Goal

**Goal**: Materialize an OpenCode adapter placeholder (structure + interface) that maps core `.ai/rules` via `instructions`, without changing core content and without a full generator.

**Success Measure**: Identical `adapters/opencode/opencode.jsonc` and root `opencode.jsonc` exist with `$schema` + §6.1 globs and PLACEHOLDER comment; README carries maturity `placeholder` and core-unchanged invariant; `.cursorignore` excludes OpenCode-only paths; CHANGELOG / `.ai/README` / mapping §6 point at materialization; review has no BLOCKER vs Jira AC (with Q3=B: full ignore triad = DHI-529 follow-up).

**Do NOT touch / do NOT add**:

- OpenCode generator/sync script (Q2=A)
- `.ai/rules/**` content
- Root `AGENTS.md` (Q6=A)
- Full `.claudeignore` / `.opencodeignore` triad (DHI-528–529) beyond minimal `.cursorignore`
- Claude adapter, sync CLI, MCP, installer/wizard
- Agent profiles / proprietary config keys
- New npm dependencies
- Committing `docs/specs/dhi-*`
