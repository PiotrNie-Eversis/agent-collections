## Wildly Important Goal

**Goal**: A production build of the docs site advertises `https://agent-collections.vercel.app` as its canonical origin.

**Success Measure**: `website/build/index.html` and `website/build/sitemap.xml` contain `https://agent-collections.vercel.app` and do not contain `localhost:3000`.

**Do NOT touch / do NOT add**:

- `vercel.json`, the Vercel Root Directory, and the dev-server bind (`docusaurus start` stays as it is; `baseUrl` stays `/`)
- Root `README.md` (it already names the live host)
- `website/static/img/opengraph.png` (the file is fine; only the host prefix is wrong)
- Example `localhost:3000` strings in `eversis-implement-ui` and `eversis-accessibility-auditing` (local dev-server examples, not site metadata)
- A new environment variable, preview-URL switch, or custom domain
- New package dependencies

## Proposed Solution

Reproduction: open https://agent-collections.vercel.app/ and view source. Canonical, `og:url`, `og:image`, and `twitter:image` use `http://localhost:3000`. The same origin appears in `sitemap.xml` and on docs pages. HTML `last-modified` was 2026-09-12.

Root cause: `website/docusaurus.config.ts` sets `url` to `http://localhost:3000` and comments that public hosting was deferred. Docusaurus copies `url` into absolute metadata and the sitemap at build time. `vercel.json` does not override it, so Vercel serves that static output. `baseUrl` is already `/` and is not the defect.

Fix: set `url` to the production origin `https://agent-collections.vercel.app` (no trailing slash, per Docusaurus). Replace the deferred-hosting comment with a note that this value is the canonical origin baked into metadata. Update the two docs that still say public hosting is deferred: `website/README.md` and the notes line in `docs/architecture/requirements-traceability.md`. Add one **Fixed** bullet under `## [Unreleased]` in root `CHANGELOG.md`. `prebuild` regenerates `website/src/pages/changelog.md`; do not edit that generated page by hand.

`url` is the canonical site origin, not the address `docusaurus start` binds. Local preview keeps working on the dev server after this change. Hardcoding the origin matches the current config (no env read) and keeps every build, including CI and Vercel, on the same canonical host.

```text
docusaurus.config.ts  url = https://agent-collections.vercel.app
        │
        ▼  npm run website:build
website/build/  canonical, og:*, hreflang, sitemap.xml
        │
        ▼  existing Vercel static deploy (unchanged in this plan)
https://agent-collections.vercel.app/
```

The site has no unit-test runner. The verifiable check is the build output, not a new test package.
