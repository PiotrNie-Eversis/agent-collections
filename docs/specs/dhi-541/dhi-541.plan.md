## Wildly Important Goal

**Goal**: Make the root README the clearest first-hour map of Agent Collections for newcomers without losing accurate install, upgrade, or MVP facts.

**Success Measure**: A new reader can answer “what is this?”, “what do I do first?”, and “what do I approve?” from the top half of the README before encountering SemVer / vendor-mode detail; all internal links resolve; CHANGELOG Unreleased notes the UX rewrite.

**Do NOT touch / do NOT add**:
- Do not rewrite `website/docs/**` or `documentation/agent-collection.md` in this task (link only)
- Do not change installer, adapters, MCP package code, or generate slash-commands / `.cursor` skill mirrors
- Do not switch README locale to Polish; do not add HTML centered hero (`<h1 align="center">`)
- Do not invent public docs hosting URL
- Do not remove versioning / upgrade / project-owned tables — only relocate and mildly shorten if needed

## Proposed Solution

Rewrite root `README.md` to follow the **cursor-collections documentation UX pattern** (progressive disclosure: hero → value → workflows with human gates → quick start → catalogs → install/upgrade deep facts), adapted to Agent Collections truths (`.ai/` SSOT, `AGENT_COLLECTIONS_HOME`, multi-adapter, full Delivery Standard including Research / Plan / Fine).

Approved research defaults (2026-08-06): English-only; Markdown-light hero with optional modest section emoji; keep shortened versioning/upgrade tables after workflows/quick start; scope = `README.md` + `CHANGELOG.md` Unreleased only.

### Target section order

```text
1. Hero (name + one plain sentence + Delivery Standard + Eversis)
2. Who it is for / what you get (plain bullets)
3. What this repository provides (by phase: Ideate / Implement / Quality / Customization / Infrastructure)
4. Prerequisites (short)
5. Supported workflows + one full-lifecycle ASCII example with Review/Approve cues
6. Human judgment callout
7. Quick start (this repository) — numbered
8. Install into a consumer project + vendor modes + migration link
9. Public prompts at a glance
10. Agents (condensed roster by phase; link full docs)
11. MCP (why → user vs workspace → build eversis-collections → short server list)
12. Versioning + Upgrade contract + project-owned files
13. Layout (folder tree)
14. Maintainers checklist
15. Related documentation table
16. Footer © Eversis
```
