## Top Failure Modes

- An empty `website/blog/` directory can fail `docusaurus build`. The post file has to exist before the phase 1 build is treated as green.
- The local-search index filename is hashed. The definition of done must accept any search file under `website/build` that contains the post slug, not one hard-coded filename.

## WARNINGS

### W1: Empty blog build

Phase 1 verification runs `npm run website:build` before the post exists. If the blog plugin rejects an empty directory, the build belongs after the draft file is on disk. That does not change the design.

### W2: Search index filename

`hashed: true` means the search asset name is not stable. Verify by searching `website/build` for the post slug and for `/docs/getting-started/start-here`, which the plan already allows.
