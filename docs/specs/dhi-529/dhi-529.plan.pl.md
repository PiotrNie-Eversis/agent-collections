## Wildly Important Goal

**Goal**: W root `agent-collections` istnieje kompletna, ręcznie utrzymywana triada ignore kodująca macierz cross-tool §4 oraz wspólne secrets/build — bez heavy-infra / area globs i bez zmian w `adapters/sync.mjs`.

**Success Measure**: Trzy pliki obecne; Cursor wyklucza `CLAUDE.md` (+ OpenCode); Claude wyklucza `.cursor/**` (+ OpenCode); OpenCode wyklucza `.cursor/**` i `CLAUDE.md`; checklista klas w `isolation-strategy.md` §8.1; CHANGELOG zaktualizowany; review bez blockerów względem AC Jira.

**Do NOT touch / do NOT add**:

- Generatory ignore / SSOT YAML (Q2≠B)
- Szablony `templates/ignore/` (Q1≠C/B)
- Wzorce heavy-infra / `apps/**` / profile obszaru (Q3=B → DHI-530)
- Zmiany `adapters/sync.mjs` / generate pod ignore (Q4=A)
- Implementacja merge w installerze (Q5 = kontrakt docs; kod = 5.2)
- `rule-map.yaml`, treść reguł core, pełny OpenCode adapter
- Empiria WNF-03 (DHI-542)

## Proposed Solution

Materializacja kontraktu §8.1 strategii izolacji jako **trzech plików w root** (Q1=A), rozszerzając istniejące `.cursorignore`.

```text
.cursorignore      (MODIFY) — + CLAUDE.md; sekcje: secrets/build | other-tool packaging
.claudeignore      (CREATE) — secrets/build + .cursor/ + opencode*
.opencodeignore    (CREATE) — secrets/build + .cursor/ + CLAUDE.md

docs/architecture/isolation-strategy.md  (MODIFY) — §8.1: „materialized” + checklista klas (Q2=A)
CHANGELOG.md                             (MODIFY) — wpis DHI-529
adapters/claude/README.md                (MODIFY) — usunąć „deferred” dla .claudeignore
(opcjonalnie krótkie pointery) .ai/README.md / adapters/README.md
```

**Klasy wymagane w triadzie (zsynchronizowane = te same klasy, składnia tool-idiomatic):**

| Klasa | `.cursorignore` | `.claudeignore` | `.opencodeignore` |
|-------|-----------------|-----------------|-------------------|
| Secrets / build | Exclude | Exclude | Exclude |
| `.cursor/**` | *(własne — nie exclude)* | Exclude | Exclude |
| `CLAUDE.md` | Exclude | *(własne — nie exclude)* | Exclude |
| `opencode.json` / `opencode.jsonc` / `adapters/opencode/` | Exclude | Exclude | *(własne — nie exclude)* |
| Heavy-infra / `apps/**` | **Brak** (Q3=B) | **Brak** | **Brak** |

**Sekcje w plikach** (nagłówki komentarzy) — żeby przyszły installer (Q5=A) mógł merge’ować braki bez wipe.

```text
# --- Agent Collections: secrets / build ---
# --- Agent Collections: other-tool packaging ---
# (opcjonalnie) # --- Consumer local ---  ← poza zakresem tej story; zostawić miejsce w docs
```
