## Overview

Extend the Cursor adapter so `npm run sync:adapters` generates thin slash-command Markdown files under `.cursor/commands/` from `.ai/prompts/{public,internal}/eversis-*.md`, and `sync:adapters:check` fails on drift. Update mapping/docs so slash emit is an optional Cursor-channel packaging (stable prompt id remains SSOT).
