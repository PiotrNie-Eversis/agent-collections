## Wildly Important Goal

**Goal**: Dostarczyć działający adapter Cursor, który generuje `.cursor/rules/*.mdc` z core według `rule-map.yaml` i zastępuje symlinki frameworkowe w `agent-collections`, z bezpiecznym re-run.

**Success Measure**: Po `node adapters/cursor/generate.mjs` siedem zmapowanych `.mdc` to zwykłe pliki (nie symlinki) z poprawnym front matter + markerem GENERATED; BA symlinki i lokalny `eversis-project-stack.mdc` nietknięte; drugi re-run jest idempotentny; review bez BLOCKER vs AC Jira.

**Do NOT touch / do NOT add**:

- Skills/prompts materializacja (Q7=A) — zostają symlinki
- Generowanie / nadpisywanie `eversis-project-stack.mdc` (Q4=A)
- Usuwanie symlinków BA (Q3=B — zostają)
- Seedy domain (backend/devops/shared-types/architecture-design) w rule-map (poza Q2=C)
- Adapter Claude / OpenCode, sync CLI (526/525/527), MCP (535), installer
- Nowe zależności npm bez osobnej zgody (prefer **zero deps**)
- Edycja `cursor-collections`; commit `docs/specs/dhi-*`


Przepływ generatora (kontrakt, bez body implementacji):

```text
1. Wczytaj rule-map.yaml (version + rules[])
2. Dla każdego wpisu: przeczytaj source .md → zbuduj YAML front matter z mapy
   → wstaw <!-- GENERATED: do not edit; re-run adapters/cursor/generate.mjs -->
   → dopisz body ze source
3. Zapisz do output (domyślnie ścieżka z mapy; jeśli --out <dir>, przepisz root wyjścia)
4. Nie zapisuj id poza mapą; nigdy nie ruszaj project-stack ani plików spoza listy output
```

### Tech Stack

- Node.js (stdlib only) — `adapters/cursor/generate.mjs`
- YAML: **ograniczony parser podshape mapy** w samym `.mjs` (zero npm) — bez dodawania `yaml` / `package.json` chyba że maintainer osobno zgodzi się na zależność
- Brak istniejącego `package.json` w root — nie tworzyć pełnego app stack; uruchomienie: `node adapters/cursor/generate.mjs`

### Code Style & Standards

- ES modules (`.mjs`)
- Jawne ścieżki względne względem **repo root** (wykryj root: katalog zawierający `.ai/` i `adapters/`, lub `process.cwd()` z wymogiem uruchomienia z roota)
- Exit code ≠ 0 przy brakującym source / niepoprawnej mapie
- Nie logować sekretów (nie dotyczy)
