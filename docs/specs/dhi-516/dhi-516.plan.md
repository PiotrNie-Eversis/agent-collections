**Success Measure**: `docs/specs/dhi-516/asset-inventory.md` exists; category row counts match live `cursor-collections` tree counts for rules (8), skills (45), prompts (28), commands (8); BRD gaps section covers WF-01 through WF-05; Code Reviewer finds no blockers against Jira AC.

**Do NOT touch / do NOT add**:
- Do not create or populate `.ai/` (DHI-517+)
- Do not move, copy, neutralize, or rewrite framework content
- Do not change installer, MCP package, website, or EOG
- Do not invent Deprecated tags without evidence
- Do not inventory `agent-collections` symlinks as the source of truth (source is always `cursor-collections`)

## Proposed Solution

Produce a single markdown inventory artifact under `docs/specs/dhi-516/` by walking the live `cursor-collections` repository (sibling checkout path used by this workspace). Apply the taxonomy and preliminary classifications from the approved research; expand every named asset to path + purpose + class + target hint. Add a BRD gaps section and a short maintainer review checklist. Optionally keep a generated machine-readable companion (CSV) only if it stays in sync with the markdown—markdown is the primary AC deliverable.

```text
cursor-collections/  --(enumerate)-->  docs/specs/dhi-516/asset-inventory.md
                         classify via research taxonomy
                         + BRD WF-01..05 gaps
```
