## Proposed approach (subject to Gap answers)

```text
cursor-collections/.cursor/skills/eversis-*
  --(copy package)-->  agent-collections/.ai/skills/eversis-*
cursor-collections/.cursor/prompts/{public,internal}/*.md
  --(copy + neutralize)-->  .ai/prompts/{public,internal}/*.md
```

**Stable id:** directory / file stem `eversis-<name>` (unchanged).

**Neutralization rules (body):**

1. `.cursor/skills/` → `.ai/skills/` (or “skill package under `.ai/skills/` / MCP `eversis_skills_*`”)
2. `.cursor/prompts/` → `.ai/prompts/`
3. Required `@eversis-*` / “attach with `@`” → stable name (“load prompt `eversis-implement`”)
4. Slash `/eversis-*` as **only** entry → note as Cursor-adapter convenience; core uses prompt id
5. Keep skill YAML `name` / `description` (tool-neutral Agent Skills shape)
6. Prompt Docusaurus frontmatter: **keep** for later docs sync (DHI-540) unless Q says strip
7. Do **not** port `.cursor/commands/`

**Accounting artifact:** `docs/specs/dhi-520/port-manifest.md` — every inventory skill/prompt row → ported path or deferred+rationale.
