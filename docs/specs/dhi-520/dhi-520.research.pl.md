## Proponowane podejście (zależne od Gap)

```text
cursor-collections/.cursor/skills/eversis-*
  --(kopiuj pakiet)-->  agent-collections/.ai/skills/eversis-*
cursor-collections/.cursor/prompts/{public,internal}/*.md
  --(kopiuj + neutralizuj)-->  .ai/prompts/{public,internal}/*.md
```

**Stabilne id:** stem `eversis-<name>` (bez zmiany).

**Zasady neutralizacji:**

1. `.cursor/skills/` → `.ai/skills/` (lub MCP `eversis_skills_*`)
2. `.cursor/prompts/` → `.ai/prompts/`
3. Wymagane `@eversis-*` → stabilna nazwa („załaduj prompt `eversis-implement`”)
4. Slash `/eversis-*` jako jedyne wejście → wygoda adaptera Cursor; core = id promptu
5. Zostaw YAML skill `name` / `description`
6. Frontmatter Docusaurus promptów: **zostaw** pod sync docs (DHI-540), chyba że Q każe usunąć
7. **Nie** portować `.cursor/commands/`

**Artefakt rozliczenia:** `docs/specs/dhi-520/port-manifest.md` — każdy wiersz inventory → ścieżka portu albo defer+rationale.
