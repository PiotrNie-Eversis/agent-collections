## Wildly Important Goal

**Goal**: Dostarczyć jedną deterministyczną komendę sync, która regeneruje wyjścia adapterów Cursor i Claude z `.ai/` oraz w trybie `--check` potwierdza brak driftu — bez ruszania konfiguracji project-owned.

**Success Measure**: `node adapters/sync.mjs` (oraz `npm run sync:adapters`) odświeża mapped `.mdc` + `CLAUDE.md`; `node adapters/sync.mjs --check` kończy się 0 gdy dysk = świeża generacja i zestawy id/source map są równe, ≠0 przy drift; `eversis-project-stack` oraz BA symlinki nietknięte; review bez BLOCKER względem AC.

**Do NOT touch / do NOT add**:

- OpenCode generate / regeneracja `opencode.jsonc` (Q2=A)
- Shared `adapters/shared/rule-map.yaml` / merge map Cursor+Claude (Q5=A — tylko assert w `--check`)
- CI workflow / pre-commit hook (Q6=A — tylko docs „dodaj do CI później”)
- Osobna sekcja docs dla konsumenta o `--out` (Q4=A — flaga działa, bez ekstra narracji konsumenckiej)
- Installer / recorded agents / merge MCP (5.x)
- Ignore triad (DHI-528–530)
- Port `sync-prompts.mjs` (Docusaurus)
- Zmiana treści `.ai/rules/*.md`; refaktor logiki emit w `generate.mjs` (tylko orkiestracja / bugfix blokujący sync)
- Nadpisywanie `eversis-project-stack`, BA Docs symlinki, `.cursor/skills|prompts`, secrets, `docs/specs|context`

```text
  docs/architecture/adapter-mapping.md  # §8: DHI-527 done + komenda
  CHANGELOG.md             # Added: adapter sync CLI
```

**Przepływ sync (pseudo — bez body implementacji):**

```text
parseArgs → { check, outRoot, adapters? }
findRepoRoot (.ai/ + adapters/)

if check:
  assertCursorClaudeIdSourceParity(rule-map cursor, rule-map claude)  # Q5=C
  tmp = mkdtemp
  run cursor generate --out tmp
  run claude generate --out tmp
  compare mapped paths: tmp vs repo (normalize LF)
    Cursor: każdy output z rule-map
    Claude: CLAUDE.md
  exit 0 | 1
else:
  run cursor generate [--out outRoot]
  run claude generate [--out outRoot]
  exit 0 | fail-fast jeśli child ≠ 0
```

```text
.ai/rules ──► cursor/generate.mjs ──► .cursor/rules/eversis-*.mdc (mapped)
           ──► claude/generate.mjs ──► CLAUDE.md
                    ▲
            adapters/sync.mjs  (jedna komenda)
```

**Wywołanie generatorów:** preferuj `node` + ścieżki absolutne do `adapters/*/generate.mjs` (spawn/`child_process` lub równoważne), **bez** kopiowania logiki emit. Propaguj `--out` 1:1.

**Allowlist zapisu (AC #2):** sync/generatory mogą zmieniać wyłącznie mapped Cursor outputs + `CLAUDE.md` (lub te same ścieżki pod `--out`). Nigdy nie wołać ścieżek project-stack / BA.

- Porównanie w `--check`: normalizuj `\r\n` → `\n`; porównuj tylko allowlist ścieżek

## Security Considerations

- Sync zapisuje tylko through existing generators + mapped paths; waliduj `--out` jako katalog (nie arbitrary file write API)
- Temp w `--check` czyść zawsze (try/finally); nie zostawiaj treści core w world-writable lokalizacjach dłużej niż potrzeba
- Nie czytaj / nie kopiuj `.env*`, secrets, `docs/specs` lokalnych
- Spawn tylko znanych skryptów w `adapters/*/generate.mjs` (hardcoded relative paths), nie user-supplied script path
- Path traversal: generatory już walidują source; sync nie dokłada luźnych ścieżek source
