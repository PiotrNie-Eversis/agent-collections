## Wildly Important Goal

**Goal**: A committed domain-knowledge entry carries a trust status the router honors, and Implement readiness can show an audit is due from a count stored on `INDEX.md`, not from a guess.

**Success Measure**: Component files written by promote and import set `status: approved`; the audit skill treats empty `code_paths` on `source: confluence` and `source: docs-specs-cluster` as “map it”; `agent-core.md` step 3 does not treat `deprecated` or `superseded` as current truth and leaves the index row; Fine increments `tasks_since_audit` once, including when nothing is promoted; a finished manual audit resets that count; the readiness block may show `Audit: never` or `Audit: N since YYYY-MM-DD` (with `due` when `N >= 5`) and never treats that line as a gate. `npm run sync:adapters:check` passes. MCP source is unchanged.

**Do NOT touch / do NOT add**:

- Do not persist `draft` or `proposed`. Those words stay names of the existing chat gate.
- Do not merge Keep / Update / Consolidate / Replace / Delete into the trust enum, and do not add a sixth audit outcome.
- Do not run the audit automatically, including on Fine.
- Do not change `mcp/eversis-collections-mcp` or add an index column. `readIndexComponents` keeps the two-column row.
- Do not edit `docs/context/global/`.
- Do not extend the empty-`code_paths` exception to `source: agent-discovered`.
- Do not increment the counter on import, and do not invent a historical count when `last_audit` is absent.
- Do not tighten Fine promotion, make `changelog.md` rollover mandatory, or touch AC-16, AC-17, AC-19, AC-20, or AC-22.
- Do not run an audit against a consumer repo. Semantic search stays out.
- Do not publish the Jira description in this plan. Hand-editing generated `.cursor/rules/` or `.claude/` is out; `sync:adapters` is the only writer.

## Proposed Solution

Two phases, both edits to existing skills and Layer A rules. No new skill, no new directory, no MCP change.

**Phase 1** stores trust on the component file and teaches the reader and the auditor what it means. Promote and import, which already commit only after a human accepts the draft, write `status: approved`. The audit skill keeps its five outcomes. Keep, Update, and Replace leave `approved`. Consolidate marks absorbed entries `superseded` with `superseded_by` pointing at the survivor. Delete still removes the file and the index row. In that same audit step the person may set `deprecated` instead of Delete when the file should remain and must not be read as current. `superseded` requires `superseded_by`. Empty `code_paths` on `source: confluence` or `source: docs-specs-cluster` means Update (map it), never Delete. `agent-core.md` step 3, after the one component file is opened, says: `deprecated` and `superseded` are not current truth; do not base the task on the body; if `superseded_by` names another component, read that one file instead; do not remove the index row.

**Phase 2** stores the audit count in frontmatter of `docs/context/<project>/INDEX.md` (the file, not a table column): `last_audit` (absent until an audit finishes), `tasks_since_audit`, `audit_due_after: 5`. Fine increments `tasks_since_audit` by one even when promotion writes nothing. Zero index rows: do not create the counter. A finished manual audit sets `last_audit` to today and `tasks_since_audit` to 0. Readiness, Layer A only, may add one optional line after `Context` and before `Reason`: omit it at 0 components; `Audit: never` when components exist and `last_audit` is absent; otherwise `Audit: N since YYYY-MM-DD`, plus `due` when `N >= audit_due_after`. The line is never a gate. The agent reads the frontmatter directly.

```text
Phase 1                                      Phase 2
-------                                      -------
promote + import examples                    fine-handoff
  status: approved on commit                   +1 tasks_since_audit per Fine
audit skill                                    (skip when the index has no rows)
  cluster empty code_paths → Update          audit skill (from Phase 1)
  superseded_by / deprecated                   resets the counter when a run finishes
agent-core.md step 3                         engineering-manager.md
  not current truth; row stays                 + orchestrating skill
                                               optional Audit line after Context
```
