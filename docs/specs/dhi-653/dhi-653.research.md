## Gap Analysis

### Question 1
#### Should the merged "Advanced / CTO" top-level navbar item keep the existing `.navbar__link--cto` purple-accent styling?

**Resolved during research**: Yes — keep it, applied to the new merged top-level item instead of only the old standalone "For CTOs" link. The accent still communicates "this is where decision-maker/advanced content lives," which is true of the merged cluster as a whole (Isolation is also an enterprise/advanced topic), not a misrepresentation. Removing the accent entirely would be a visual regression with no stated reason to do so; keeping it as a standalone extra highlighted item alongside a separate "Advanced" entry would contradict the ticket's explicit AC to merge the two into one entry.

### Question 2
#### Should the merged items be dropdowns (revealing sub-pages), or plain links?

**Resolved 2026-09-05 (stakeholder decision, supersedes the research-time default below): plain links, no dropdown.** Each of the 3 merged navbar entries (The Main Flow, Reference, Advanced / CTO) becomes a single direct link to that cluster's landing page (`main-flow/index.md`, `reference/index.md`, `advanced/index.md`) — exactly the same pattern the existing "Get started" item already uses (a direct link to `getting-started/start-here.md`, its own landing/first page). This is simpler than a dropdown and makes all 4 cluster items in the navbar behave identically. The landing page's own ":::info Start here" signpost (DHI-643) and "In this section" list already provide the sub-page navigation a dropdown would have duplicated — no navigation capability is lost, just relocated one click deeper, consistent with how "Get started" already works today.
