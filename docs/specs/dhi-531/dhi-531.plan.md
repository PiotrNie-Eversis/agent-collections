## Wildly Important Goal

**Goal**: Ship a tool-neutral `AGENTS.md` standard and consumer template so any agent can locate monorepo areas, agent roles, and framework entry points without Cursor-only instructions.

**Success Measure**: Committed `docs/architecture/agents-md-standard.md` + `templates/AGENTS.template.md` exist; root `AGENTS.md` follows the template section shape with placeholders; main body has no `@` / `.cursor/` as primary instructions; install contract is documented for 5.x.

**Do NOT touch / do NOT add**: Full reference fill (DHI-532); installer CLI; adapter generators / sync behavior; legacy cursor-collections stub; Polish content; long stack/constitution prose in AGENTS.

## Proposed Solution

Per research Gap Q1–Q6 (locked):

1. Author **normative standard** at `docs/architecture/agents-md-standard.md` (required sections, neutralization dictionary, role-matrix rules, docs triad `docs/{context,plans,specs}`, install contract create-if-absent).
2. Author **copyable template** at `templates/AGENTS.template.md` matching the standard (placeholders for Areas / Project specifics; full agent role matrix; optional Cursor channel appendix with `/` and `@`).
3. **Restructure** root `AGENTS.md` to the same section shape with short framework pointers and placeholders (not DHI-532 full reference).
4. Add pointers from root `README.md` and `.ai/README.md`; add `docs/plans/README.md` for triad parity; brief CHANGELOG note under Unreleased or 0.0.1 Added.

```text
docs/architecture/agents-md-standard.md  ← norm

AGENTS.md (root)                         ← template-shaped scaffold (Q2=B)

```
