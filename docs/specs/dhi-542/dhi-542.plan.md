## Technical Context

### Project Instructions

- Delivery Standard: research → plan → implement → review → Fine (`eversis-orchestrating-implementation`)
- Path policy: no `/Users/…` or other machine-local absolutes in committed docs — use repo names, relative paths, `$AGENT_COLLECTIONS_HOME` / `${env:AGENT_COLLECTIONS_HOME}`
- Q7: never commit `portal`/`cms` into framework `adapters/profiles/*.yaml`

### Architecture & Patterns

- **Local mode:** framework SSOT stays outside EOG; skills via MCP `eversis-collections`
- **Generated vs project-owned:** regenerate rules/`CLAUDE.md` via installer `--sync`; never overwrite customized stack / `AGENTS.md` without opt-in
- **Ignore merge:** framework blocks use `# agent-collections … [begin/end]`; consumer overlay must use a **distinct** marker so `--sync` / area apply does not wipe it
