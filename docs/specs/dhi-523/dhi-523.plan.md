### Architecture & Patterns

**Canonical doc path:** `docs/architecture/adapter-mapping.md`

**Cursor field map (from legacy `.mdc`):**

| Field | Type | Use |
|-------|------|-----|
| `description` | string | Rule summary for Cursor UI |
| `alwaysApply` | bool | Always-on core (sparingly) |
| `globs` | string[] | Path patterns; empty + `alwaysApply: false` = attach-only |

**Packaging classes → rule-map entries:**

| Class | Typical core source | Cursor packaging |
|-------|---------------------|------------------|
| Always-on | `orchestration/agent-core`, `testing-and-terminal` | `alwaysApply: true` |
| Glob-scoped | `frontend/accessibility` | `globs: […]` |
| Attach-only | `engineering-manager`, `code-reviewer`, BA roles | `globs: []`, `alwaysApply: false` |

**Consumer-owned:** `project-stack` — map may list it as consumer template; adapter must not overwrite without opt-in (DHI-521).

**rule-map.yaml contract (document only — no file in this story):**

```yaml
# Illustrative shape for DHI-524 — not committed in DHI-523
version: 1
rules:
  - id: eversis-agent-core
    source: .ai/rules/orchestration/agent-core.md
    output: .cursor/rules/eversis-agent-core.mdc
    description: "…"
    alwaysApply: true
  - id: eversis-accessibility
    source: .ai/rules/frontend/accessibility.md
    output: .cursor/rules/eversis-accessibility.mdc
    description: "…"
    globs: ["**/*.tsx", "**/*.jsx", "**/*.vue", "**/*.html", "**/*.svelte"]
```

Spec must define required keys (`id`, `source`, `output`, `description`, and exactly one of `alwaysApply` / `globs` packaging mode) and note that DHI-524 creates the real file + generator.

**Claude Code (Q4 A):**

- Output: single root `CLAUDE.md`
- `scope` → which core domains/sections are inlined (orchestration always; domain sections per profile later — for 523, document section-per-core-rule or section-per-domain; prefer **one H2 section per mapped core rule file** for unambiguous 2.3)
- `commands` → document as **out of Cursor slash-command sense**: Claude adapter may list “load prompt id X” as instructional commands inside `CLAUDE.md` or defer native Claude commands to later; **do not** require `.cursor/commands` emission
- Skills/prompts: **not** emitted by Claude adapter in MVP (MCP / AGENTS)

**OpenCode placeholder (Q6 B) — align to public docs (https://opencode.ai/docs/rules):**

```json
{
  "$schema": "https://opencode.ai/config.json",
  "instructions": [
    ".ai/rules/orchestration/*.md",
    ".ai/rules/frontend/*.md"
  ]
}
```
